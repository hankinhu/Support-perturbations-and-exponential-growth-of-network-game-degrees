# Network-game degrees: reproducibility code

Companion materials for **Support perturbations and exponential growth of network-game degrees**, by Hangkun Hu, Jingyi Wang, and Minggang Wang (AAM submission 2.0).

## Requirements and execution

Use **Python 3.10 or later**. Only the Python standard library is used; no package installation, external dataset, or LaTeX installation is needed to run the verification programs. The support programs use `int.bit_count()`, which requires Python 3.10+.

Keep the files together and run the following commands from this directory, using normal Python execution (without `-O`, because the checks use assertions):

```text
python verify_support_perturbations.py
python verify_activation_threshold.py
python verify_sparse_example.py
python verify_security_example.py
```

The activation program imports `verify_support_perturbations.py`; these two files must remain in the same directory.

## Files and manuscript correspondence

| File | Purpose |
| --- | --- |
| `verify_support_perturbations.py` | Independently enumerates small balanced tables and checks support-difference identities, essential-support equivalences and finite activation. |
| `verify_activation_threshold.py` | Checks the residual Hall threshold formula (Corollary 4.2) against enumerated support differences, including the three sparse perturbation examples in Sections 5.1-5.3. |
| `verify_sparse_example.py` | Reproduces Table 1 in Section 5.4 and checks exact margins, matrix scaling, covariance and small-dilation coefficient counts. |
| `verify_security_example.py` | Checks the illustrative binary security-investment model in Section 5.2 through pure-action averaging, complete elimination and exact Jacobian checks. |
| `sparse-example-table.tex` | Editable table generated by the sparse-example program; rendering it is optional. |
| `sparse-example-verification.json` | Generated numerical table values and exact scaling/covariance information. |
| `verification-summary.json` | Summary of the completed code checks and the minimum Python version. |
| `CITATION.cff` | Citation metadata for these reproducibility materials. |
| `.gitignore` | Ignores Python cache files. |

## Expected results

- Support program: 3,357 support-difference identities, 288 equality/essential-support/dilation equivalences, and 950 finite activation checks. It also checks the three-player boundary deficit and asymptotic prefactor numerically.
- Activation program: 1,107 exact threshold/inessentiality checks and 6,560 threshold-versus-enumeration comparisons.
- Sparse program: exact rational scaling and covariance checks, independent coefficient calculations at dilations 1, 2 and 3, and table values at dilations 1, 2, 5, 10 and 20. It overwrites the supplied `.tex` table and numerical `.json` output in this directory.
- Security program: 1,296 independent pure-profile averaging checks and five exact root/regularity checks. The four networks have isolated complex counts `1, 1, 1, 2` and totally mixed equilibrium counts `1, 0, 1, 2`.

The first, second and fourth programs print results without changing files. Successful execution finishes without an assertion failure and reports the completed checks.
